# Source check

Targeted primary-source checks completed during the presenter-notes pass. This is not yet a complete fact-check of the talk.

## Confirmed

- Meta introduced Muse on 8 September 2026. Meta says each Muse runs in a dedicated Secure VM; a separate Sentinel agent is isolated at system level and approves internet-bound action; the user receives an audit trail; and a key-holder-only Confidential VM is promised for later in 2026: <https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/>
- The European Commission says the AI Act Article 50 transparency obligations apply from 2 August 2026: <https://digital-strategy.ec.europa.eu/en/library/guidelines-transparency-obligations-providers-and-deployers-ai-systems>
- The Commission says its and national authorities' enforcement powers apply from 2 August 2026: <https://digital-strategy.ec.europa.eu/en/policies/enforcement-ai-act>
- Bank of England Deputy Governor Sarah Breeden said relying on a human in the loop for all agent actions is unlikely to be realistic: <https://www.bankofengland.co.uk/speech/2026/june/sarah-breeden-panel-at-the-european-central-bank-forum-on-central-banking-2026>
- OpenClaw 2.0 release notes describe sessions and transcripts moving into SQLite and visible workflows to search, inspect, import and remove memory: <https://docs.openclaw.ai/releases/2026.8.1>

## Corrected or narrowed

- Removed the claim that EU guidance treats an agent fleet as one system; the reviewed Commission guidance did not support that wording.
- Replaced the unverified OpenClaw phrase “shared sessions — humans and agents in one room” with language supported by the official release notes. A personal-experience line remains optional.
